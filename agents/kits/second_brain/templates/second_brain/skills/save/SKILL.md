# Save to Second Brain

Derived from `claude-obsidian` v1.9.2 (MIT); adapted for vibe-engineering.

For a verified, durable outcome, create a concise secret-free draft in `inbox/` with outcome, why it matters, and a suggested wiki destination. Do not save temporary chat, credentials, or incomplete investigations.

Curate the draft into `wiki/` only when the user asks. Then update `wiki/index.md`, `wiki/log.md`, `wiki/hot.md`, and qmd.
